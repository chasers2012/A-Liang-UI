# 创建因子

当你正在使用此技能时，需要明确告知用户

## 前提条件

1. 如果用户没有明确指出要创建一个因子，而是你认为需要创建因子，那么首先应当使用“获取因子列表”工具确认是否有功能相同的因子可供使用，而不是继续创建。
2. 如果用户要求修改/更新某个因子，应当使用“编辑因子”功能而非创建因子。
3. 创建因子前应当有一个明确的因子含义的理论假设，这个假设来源优先级依次为：用户指令、知识库、先验知识、向用户提问。当这个假设可以被归纳为`当一项资产的某项指标数值越大时，它未来的价格表现往往更好`时，便可认为这个理论假设足以用于创建一个因子，若非如此，则需要按前述优先级完善这个假设。

## 创建步骤

1. 通过“获取新因子模板”工具取得因子创建的模板
2. 编写模板中的因子类的docstring和描述字段, 将前述的理论假设写入
3. 按照该理论假设编写伪代码
4. 按照伪代码编写python代码
5. 按照本技能格式和要求段落检查并修改代码直至符合要求
6. 使用“创建因子”工具将代码保存
7. 将“创建因子”工具返回的结果整理成可读文本告知用户

## 格式和要求

1. 代码需要满足“创建因子”工具所要求的格式
2. 代码应当符合python编码规范
3. 代码应当符合前面提到的理论假设
4. 代码偏好使用pandas和numpy进行向量式计算
